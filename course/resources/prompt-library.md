# The AI for Everyday Work Prompt Library

**60 copy-and-paste prompts.** Replace anything in [brackets]. Works in ChatGPT, Claude, Gemini and Microsoft Copilot. Free versions are fine unless a prompt says otherwise.

**Before you paste anything:** remove private information (names, ID and account numbers, medical or confidential details). **Check it. Protect it. Own it.** You're responsible for what you send or submit.

**Universal add-on** (add to any prompt): *"Don't invent facts. Use [PLACEHOLDER] where you need information from me, and ask me questions first if anything is unclear."*

---

## A. Prompting basics (8)

**A1. The 4-part formula**
```
Act as [role]. I'm [who I am and my situation]. Background: [context]. Please [one clear task]. Format: [format, length, tone]. Before you answer, ask me any questions you need to do this well.
```

**A2. Quick version**
```
[Task]. Format: [format and length]. Audience: [who will read it].
```

**A3. Ask me questions first**
```
I want to [goal]. Before you answer, ask me up to 5 questions that would help you do this well. Wait for my answers.
```

**A4. Say when you don't know**
```
Answer the question below. If you're not sure or don't have enough information, say so instead of guessing, and tell me what to verify.

Question: [question]
```

**A5. Extract my writing style**
```
Below are three samples of my own writing. Describe my style in 5 bullets (sentence length, tone, vocabulary, habits, things I avoid), specific enough for someone to imitate.

Sample 1: [paste]
Sample 2: [paste]
Sample 3: [paste]
```

**A6. Write in my style**
```
Write [task] for [audience]. Use this style: [voice note]. Avoid clichés, buzzwords and phrases like "I hope this email finds you well." Keep it under [length]. Don't invent facts.
```

**A7. Three options**
```
Give me 3 different versions of [opening / subject line / closing / headline]. Label them A, B, C, and say in one line how they differ.
```

**A8. Turn a good prompt into a template**
```
Turn this prompt into a reusable template. Replace details that change with [brackets], add a one-line description of when to use it, and suggest one improvement.

Prompt: [paste]
```

## B. Fix-it follow-ups (6)

**B1. Shorten**
```
Make this shorter: about [X] words. Keep [key points].
```

**B2. Change tone**
```
Change the tone to [warmer / more direct / more professional / more casual]. Keep the meaning the same.
```

**B3. Fix one part**
```
The part that says "[quote]" isn't working because [reason]. Rewrite only that part.
```

**B4. Add what's missing**
```
You left out [fact]. Add it and change nothing else.
```

**B5. Self-check**
```
Check your answer for mistakes. List anything you're unsure about and show your steps.
```

**B6. Fresh start summary**
```
Summarize what we've decided so far in 5 bullets so I can start a new chat with a clean context.
```

## C. Email (10)

**C1. Bullets to email**
```
Write an email from me ([role]) to [recipient and relationship]. Goal: [what I want]. Key points: [bullets]. Tone: [tone]. Under [X] words. Include a subject line. Don't invent details.
```

**C2. Reschedule a meeting**
```
Write a short email to [name] asking to move our [meeting] from [current time] to one of these options: [options]. Same agenda. Brief apology, friendly tone, under 80 words.
```

**C3. Polite follow-up**
```
Write a polite follow-up to [name] about [topic]. I first emailed on [date]. Friendly, not pushy, under 60 words.
```

**C4. Decline politely**
```
I need to decline [request] from [person]. Keep the relationship positive, be honest (no invented excuses), and offer [alternative or nothing]. Under 100 words.
```

**C5. Ask for a deadline extension**
```
Write an honest email to [instructor/manager] asking for a [X]-day extension on [task] due [date]. Reason: [true, brief reason]. Show I've already done [progress]. Propose a new date: [date]. Under 100 words.
```

**C6. Reply with my decision**
```
Draft a reply to the email below. My decisions: [yes to X / no to Y / question about Z]. Tone: [tone]. Under [X] words. Don't add facts I haven't given you.

Email: [paste]
```

**C7. Summarize a thread**
```
Summarize this thread in 5 bullets: decisions made, open questions, who owes what, and deadlines. List anything unclear under "Unclear."

Thread: [paste, names replaced by initials]
```

**C8. Proofread only**
```
Proofread only: fix spelling, grammar and punctuation. Don't change wording or tone. List what you changed.

Text: [paste]
```

**C9. Tone check**
```
Read this email as [recipient]. How might it come across? Is anything unclear, too blunt or easy to misread? Suggest up to 3 small changes, not a full rewrite.

Email: [paste]
```

**C10. Thank-you note**
```
Write a short, sincere thank-you email to [name] for [what they did]. Mention one specific detail: [detail]. Under 80 words. No exaggerated praise.
```

## D. Spreadsheets (8)

**D1. Write a formula**
```
I'm using [Excel / Google Sheets]. Data starts in row [2], headers in row 1. Columns: [A: name, B: name…]. I want [goal in plain English] in [cell/column]. Give me the formula for the first row, explain each part, and tell me what to double-check.
```

**D2. Explain a formula**
```
Explain this formula in plain English, one part at a time: [formula]
```

**D3. Clean a column**
```
I'm using [app]. Column [X] has [description with 3–5 fake examples]. Give me a formula or steps to [clean into this format]. Show row 2, explain edge cases, and how to flag anything it can't handle.
```

**D4. Flag duplicates**
```
How can I flag duplicate rows in [app] without deleting anything? Column [X] is the key.
```

**D5. Find patterns (no math)**
```
Here's a small sample of my data: [paste, no personal info]. Describe up to 3 patterns and list questions to investigate. Don't state exact totals; give me formulas instead.
```

**D6. Build a tracker**
```
I'm using [app]. Design a simple [tracker/budget] for [my situation]. I want to track [list]. Give me column headers, a dropdown for [field] with these options [list], formulas for totals, and step-by-step setup. Use placeholder values.
```

**D7. Debug an error**
```
This formula shows [error]: [formula]. My cells contain: [description with fake examples]. What are the most likely causes, and how do I check each?
```

**D8. Sanity checks**
```
This formula runs without errors but I'm not sure it's right: [formula]. How could it be wrong with data like [description], and what quick checks can I run?
```

## E. Resume, cover letter, LinkedIn, interviews (10)

**E1. Bullet builder**
```
Turn these notes into [3] resume bullets for [target role]. Use only the facts below; don't invent numbers, tools, results or titles; start each with a strong action verb; max 25 words; if you need more information, ask me first.

Notes: [paste]
```

**E2. Truth check**
```
Compare these resume bullets with my original notes. List anything in the bullets not supported by the notes.

Notes: [paste]
Bullets: [paste]
```

**E3. Extract job requirements**
```
Here's a job posting. List the 8 most important requirements, separated into must-haves and nice-to-haves, plus recurring keywords.

Posting: [paste]
```

**E4. Resume gap analysis**
```
Compare my resume bullets to those requirements. Tell me which bullets match, which requirements aren't covered, and how to reword existing bullets using the posting's language ONLY where it's accurate. Don't suggest adding experience I don't have.

Resume: [paste without contact info]
```

**E5. Cover letter from notes**
```
Write a cover letter (max 250 words) for [role] at [company]. Use only the notes below. Don't invent achievements, numbers or company facts. Avoid clichés. Style: [voice note].

Job summary: [paste]
Notes: [why this company / 2 experiences / what I want to do]
```

**E6. Hiring manager read**
```
Read this cover letter as a hiring manager with 30 seconds. What stands out? What sounds generic? Which sentences could be cut? Don't rewrite the whole thing.
```

**E7. LinkedIn headline**
```
Give me 5 LinkedIn headline options under 120 characters. Use only these facts: [major, school, interests, target industry]. No buzzwords.
```

**E8. LinkedIn About**
```
Write a first-person LinkedIn About section of 4 sentences. Use only these facts: [notes]. Style: [voice note]. No clichés. End with what I'm looking for: [goal].
```

**E9. Mock interview**
```
Act as a realistic interviewer for [role] at [type of company]. Ask one question at a time and wait for my answer. After each answer, give feedback in 3 sentences or fewer, plus one suggestion. Do 5 questions.
```

**E10. STAR check**
```
Here's my answer to "[question]". Did I use the STAR structure (Situation, Task, Action, Result)? What's missing? Suggest one way to make it more specific without adding facts I didn't give.
```

## F. Study (8)

**F1. Explain a concept**
```
Explain [concept] as if I'm new to [subject]. Use plain English and one everyday analogy. Then ask me 1 question to check my understanding.
```

**F2. Study guide from my notes**
```
Turn my notes into a study guide with headings, key terms with short definitions, and 3 things likely to be tested. Use only my notes; list anything unclear at the end.

Notes: [paste]
```

**F3. Teach-it-back feedback**
```
Here's my explanation of [concept]. What did I get right? What did I miss or get wrong? Don't rewrite it.

My explanation: [paste]
```

**F4. Flashcards**
```
Using ONLY these notes, make [15] flashcards as a table: Question | Answer. Answers under 20 words. After the table, list anything unclear or possibly incorrect in the notes.

Notes: [paste]
```

**F5. Quiz me**
```
Quiz me on these notes, one question at a time. Mix multiple-choice and short answer. Wait for my answer, tell me if I'm right, explain why, then continue. After 10 questions, summarize my weak spots.

Notes: [paste]
```

**F6. Study plan**
```
Create a [number]-day study plan starting [date]. Deadlines: [list]. Fixed commitments: [list]. Study time available: [hours]. Weak topics: [list]. Be realistic, include breaks, active recall and practice questions. Table: Day | Task | Time.
```

**F7. Hint, not answer**
```
I tried this problem and got [answer]. My work: [paste]. Don't give me the solution yet. Give me a hint about where my reasoning might have gone wrong.
```

**F8. Feedback on my thesis**
```
Here's my thesis statement: "[paste]". Don't rewrite it. Ask me 3 questions that would help me make it clearer and more specific, and point out any weakness in my reasoning.
```

## G. Side project (6)

**G1. Idea generator**
```
I'm [who]. I have [X hours/week] and [budget]. My skills: [list]. My interests: [list]. Give me 10 side-project ideas that fit these limits, with one sentence on who the customer would be.
```

**G2. Skeptical friend**
```
Act as a skeptical, experienced friend. For this idea: [idea]. Give me the 5 biggest reasons it might not work, and what I could check this week for each. Don't invent statistics.
```

**G3. 30-day test plan**
```
Idea: [idea]. I have [hours/week] and [budget]. Create a 30-day plan to test whether people want this. Weekly tasks under [X] minutes each, one clear success measure, and a list of legal or rule questions to check with official sources.
```

**G4. Product description**
```
Write 3 versions of a product description (under [X] words). Use ONLY these facts: [list]. Audience: [who]. Style: [voice note]. Don't add features or claims that aren't listed.
```

**G5. Post ideas**
```
Give me 10 post ideas for [platform] for [audience], based on [what I sell/do]. Only ideas I can make with a phone in 30 minutes.
```

**G6. Customer reply templates**
```
Turn these policies into [4] short, friendly reply templates in my style. Use [BRACKETS] for anything that changes. Don't add policies I haven't listed.

Policies: [paste]
```

## H. Accuracy, privacy and integrity (4)

**H1. Confidence markers**
```
Answer the question below. Only include information you're confident about. Mark anything uncertain with [VERIFY]. Do not invent sources, quotes, statistics or links. If you don't know, say so.

Question: [paste]
```

**H2. List the claims to check**
```
List every factual claim in the text below (numbers, names, dates, quotes, sources) so I can verify each one. Don't say whether they're true.

Text: [paste]
```

**H3. Placeholder-ize sensitive text**
```
Help me rewrite the details below with placeholders. Replace names, companies, numbers, addresses and anything identifying with [PLACEHOLDERS], and list what you replaced.

Text: [paste only if it has no highly sensitive data]
```

**H4. Integrity check**
```
I'm thinking of using AI to [task]. Rules I know: [school/work policy]. Help me think through (1) whether this is likely allowed, (2) what could go wrong, (3) a safer way to use AI here. Remind me to confirm with [instructor/manager].
```
